# 学者 · 知识地图 v0.1 — build spec (for the coding agent)

Repo: /workspace/scholar-engine. Read first: AGENTS.md (constraints: zh-CN UI, static-first, no CDN/fetch/ES module imports, escape user content, escape `</script` when injecting JSON), roadmap/stages.py (STAGES, DRIVERS), course/graph-civilization.yaml, docs/refs/knowledge-presentation-survey-2026-10.md (sections 五).
Do NOT modify profile/, units/, roadmap/stages.py. Python 3 stdlib only for builders (no pip installs). No network at runtime.

## Deliverables
1. `docs/knowledge-map-v0.1.md` (zh-CN, concise, 结论先行). Data model:
   - ONE global node table. Node kinds: `domain` > `topic` > `node` (concept/event/era). Topics are *views* over the single graph (Heptabase-style): a node can appear in several topics via `topic.members` (with optional x,y), never copied.
   - Typed edges: `prereq`(建议先学, not a hard lock) / `belongs`(属于) / `causes`(导致) / `leads_to`(铺垫下一步) / `contrast`(对照) / `related`(相关) / `parallel`(同期平行). Each edge: id, src, dst, kind, note, claim_type (事实/学界共识/主流解释/有争议/AI推断).
   - Mastery 5 levels: `locked`(前置未亮, shown translucent; still openable) / `seen` / `learning` / `lit` (3 quiz all correct) / `mastered` (later: spaced review passed). No percentages.
   - Learning log: append-only events {ts, node, action: open|play|quiz|lit|note|topic_create|link_create, payload}.
   - Persistence: v0.1 = seed JSON embedded in HTML + user layer (progress, log, user topics, user edges) in localStorage key `scholar.map.v1`, export/import JSON file. v0.2 desktop (Tauri) = SQLite with tables node/edge/topic/topic_node/mastery/event_log/asset/source (copy schema from survey); user-layer JSON is the migration format. Seed vs user layer merge rules (user never overwrites seed content; user-created ids prefixed `u-`).
   - How other bots add content: append nodes/edges to knowledge/world-map.json (or a new knowledge/topics/*.json later), run build.
   - v0.2 roadmap section.
2. `knowledge/build_world_map.py` → writes `knowledge/world-map.json` (UTF-8, pretty). Imports roadmap/stages.py (sys.path). Content:
   - domains (≈10): 自然科学(物理/化学/天文/地球科学), 生命科学(生物学/进化/医学), 数学与逻辑, 工程与技术(能源/计算机/材料), 社会科学(经济学/政治学/社会学/心理学), 历史(人类文明通史, 中国史, 科技史), 哲学与宗教(轴心哲学/世界宗教/伦理学), 艺术与人文(视觉艺术/文学/音乐), 语言(语言学/文字), AI(机器学习/大模型与智能体/AI治理). Each domain has id, name, icon, color, 2-4 topics; most topics have 1-3 stub concept nodes (status "stub", one-line summary) so cross-links have targets: e.g. 驯化与遗传(生物学), 热力学与能量转换(物理), 化石能源(能源), 文字系统(语言/文字), 印刷与信息媒介(计算机/科技史), 轴心哲学流派, 世界宗教起源, 科学方法, 民族国家理论(政治学), 市场与货币(经济学), 深度学习/Transformer(AI), 传染病与人口(医学), 地理与气候(地球科学).
   - Topic `t-civ` 历史 > 人类文明通史 fully populated: 11 nodes from STAGES (id = stage id s1..s11, keep: name, short, icon, dates, ya, mark, core, mech, abc, east, west, facts, interp, next, lenses, weeks) + DRIVERS values per stage (driver lines: 能量/信息载体/协作规模/观念) + `quiz`: 3 single-choice Qs per stage written strictly from that stage's facts/dates in stages.py (4 options, answer index, short explain; one Q may be about distinguishing fact vs interpretation). Edges: s1→s2→…→s11 `leads_to` (note = stage.next); cross-domain edges with notes, at least: 农业革命↔驯化与遗传 (related), s2→传染病与人口 (causes), s3↔文字系统, s4↔轴心哲学流派 & 世界宗教起源, s5↔市场与货币, s6↔印刷与信息媒介, s7↔传染病与人口 (哥伦布交换), s8↔科学方法, s9↔热力学与能量转换 & 化石能源 & 民族国家理论, s10↔计算机 node, s11↔深度学习/Transformer & AI治理; plus `parallel` edge east/west not needed. Include `prereq` edges from graph-civilization.yaml where meaningful (map week nodes to stages loosely is optional—skip if unclear).
   - top-level meta: version "0.1", updated date, claim note "边为 AI推断，待 focus 审".
3. `map/template.html` + `map/build_map.py` → `out-map/学者-知识地图-v0.1.html`: single self-contained file, inline CSS/JS, works over file://, no external fonts/scripts/images/fetch. JSON injected by replacing placeholder `/*__WORLD__*/null` once, with `</` escaped as `<\/`. Builder also copies output to /workspace/share/学者-知识地图-v0.1.html.
   Vanilla JS, hand-rolled tween/timeline engine (requestAnimationFrame, easing). Dark cinematic aesthetic (deep navy/black, subtle animated starfield canvas background, glows), zh-CN, system fonts (PingFang SC, Noto Sans CJK SC, sans-serif).
   ### Views
   a) **星图 (map)**: SVG or canvas world of the graph. Domains as large nebula clusters arranged in a ring/galaxy; topics as constellations around their domain; nodes as stars. Zoom (wheel/pinch/buttons) + pan (drag); semantic zoom: far = domain labels; mid = topic labels; near = node labels. Clicking a domain/topic smoothly animates camera (tween viewBox/transform, ~800ms ease-in-out) to fit it. Edges drawn as faint curved lines; typed edge colors with legend; hover a node highlights its edges & neighbors. Mastery styling: locked = translucent, seen = dim white, learning = pulsing amber ring, lit = bright glow (animated halo), mastered = gold. HUD: title "学者 · 知识地图", counts "已点亮 X / 共 Y" (count, not percent), search box (filter/fly-to node by name), buttons: 时间轴, 新建 topic, 导出, 导入, 重置视角, 图例.
   b) **时间轴 (overview, Histography-style)**: full-screen log-time axis (from 2.8M years ago to today) with the 11 history stages as stars on the axis (span bars + star at `mark`), labels, era bands; scroll/drag to zoom the axis; click star → opens node cinematic view. Shows "有文字的历史只占 ≈0.19%" callout.
   c) **节点影片 (cinematic node view)** for every history node s1..s11: full-screen overlay, auto-playing timeline of ~40-50s built procedurally from node data, with scenes (each with entrance/exit motion):
      1. 片头: stage number + icon + name, big typographic reveal; dates line.
      2. 时间缩放: log-time axis that animates zooming from the full 2.8M-year span down into this stage's [ya] window, a marker drops in.
      3. 地图: stylized simplified SVG world (hand-drawn low-poly continent polygons — approximate shapes are fine, just recognizable: Africa, Eurasia, Americas, Australia), with animated region highlights/pulses and routes drawn with stroke-dashoffset for this stage (define per-stage regions/routes in a small table in the template: s1 out-of-Africa arrows; s2 multiple centers: 新月沃地, 华北, 长江, 中美洲, 安第斯, 新几内亚; s3 两河/埃及/印度河/黄河; s4 希腊/以色列/印度/中国; s5 罗马/波斯/孔雀/秦汉 + 丝路 line; s6 伊斯兰世界/宋/欧洲/蒙古 sweep; s7 Atlantic + Manila galleon + 郑和 routes; s8 Europe network + 北京; s9 英国 radiating rail/steam to EU/US/日本; s10 global grid/network; s11 data-center glow points US/China + global links).
      4. 三条驱动力: three animated icon cards 能量⚡ / 信息📡 / 组织🤝 each with the stage's mech text appearing beat by beat; plus 观念💡 driver line.
      5. 关键事实 beats: facts typed/fade-in one by one, labelled "事实".
      6. 东西对照: split screen, East left / West right, sliding in from both sides.
      7. 解释框架: interp cards, each labelled "解释 · 非定论" with author; ⚠ shown as amber "有争议" badge.
      8. 下一步: "它为下一步铺了什么" text, then animated transition (star trail) toward next node's name, button "去下一节点 →".
      9. 自测: 3 single-choice Qs; answers clickable; all 3 correct → node becomes `lit` with a satisfying glow/particle burst animation, saved, and map star updates. Wrong answer shows explain. Pause points: the timeline auto-pauses at the 自测 scene (Fallen-of-WWII style) and also offers "暂停探索" — while paused in the map scene user can hover regions.
      Controls: play/pause button, scrub bar with scene markers (clickable chapter ticks with scene names), elapsed/total time, keyboard: Space play/pause, ←/→ prev/next scene, Shift+←/→ prev/next node, Esc close. Timeline must be deterministic from time t (render(t) pure function of t per scene) so scrubbing works and so tests can seek: expose `window.__seek(nodeId, seconds)` and `window.__openMap()` / `window.__openTimeline()` for headless screenshots; support URL hash `#node=s4&t=12` and `#view=timeline` to open directly at a time, paused.
      Opening a node marks it `seen` (if unseen), playing past half marks `learning`.
      Non-history stub nodes open a simple card (summary + links + "待生成" note + mark lit button).
   d) **新建 topic**: modal: name, domain (select), description; then pick existing nodes to include (search list, multi-select) and optional new edges (choose kind) between them; saved in localStorage user layer; appears on map as a new constellation under that domain with its member nodes linked by dashed lines (members remain the same global nodes). User topics deletable.
   e) Export/import: download JSON {schema:"scholar.map.user.v1", progress, log, topics, edges}; import merges.
   Facts exactly from data; interpretations always labelled. Escape all text via textContent or an esc() helper. Must look good at 1440x900 and usable at 390px width.
4. Add `npm run map:build` script in package.json → `python3 knowledge/build_world_map.py && python3 map/build_map.py`.
