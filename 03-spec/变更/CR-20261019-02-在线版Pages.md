- 所有者 / 分支：cloud/grok · `cloud/grok/TASK-008-pages`
- 来源功能编号：F-07（星图主视图）、F-10（点亮 / 导出）；新增 F-15 在线版

## 1. 需求（EARS）
- R1：当 focus 打开 `https://lichangfocus.github.io/agent-graph-learning/` 时，系统应直接显示星图（Atlas 10 领域 / 47 节点），桌面与手机都可用。
- R2：站点只含公开框架与示例数据包；当构建环境设置了 `LEARN_DATA_DIR` 时，构建应失败。
- R3：站点内所有资源用相对路径，适配 `/agent-graph-learning/` 子路径。
- R4：旧链接 `maps/ai-training/…`、`maps/sound-journey/`、`my/` 继续可访问。
- R5：每次重新发布都能从 `version.json` 看到部署的提交号。

## 2. 验收标准
- AC1：Given 线上网址 When curl Then 200，标题为「学者 · 人类知识星图」，有 favicon、manifest、viewport。
- AC2：Given 1280×800 与 390×844 无头浏览器 When 打开首页 Then 星图渲染（截图存 `/workspace/share/学者-在线版-*.png`）。
- AC3：Given `LEARN_DATA_DIR=/tmp/x` When `npm run site:build` Then 退出码非 0。
- AC4：Given 产物 When 扫描 Then 不含 `learn-data/`、`units-private`、本机绝对路径、主机名。
- AC5：`maps/ai-training/index.html` 线上 200。

## 3. 设计（最小变更）
- `engine/templates/atlas-map/template.html`：标题、description、theme-color、内联 SVG favicon（离线单文件也有图标）。
- `engine/pipeline/build-site.ts` + `npm run site:build`：调用 `build-demo`（DEMO_OUT=site-dist），复制 `maps/` `my/`，写 `favicon.svg`、`manifest.webmanifest`、`404.html`、`.nojekyll`、`version.json`，最后做隐私 / 绝对路径扫描。
- 部署：`04-开发/deploy/publish-pages.sh` 把 `site-dist/` 推到孤立分支 `gh-pages`；Pages 来源从 `main /` 改为 `gh-pages /`。
- 为什么不用 GitHub Actions：box 上的 token 没有 `workflow` 权限，推不了 `.github/workflows/`。模板放在 `04-开发/deploy/pages.yml`，focus 在 Mac 上挪进 `.github/workflows/` 并把 Pages 来源改成 GitHub Actions 后，就能在每次 push `dev/latest` 时自动部署。
