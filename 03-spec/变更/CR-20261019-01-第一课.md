# CR-20261019-01 · 第一课：怎样读通史 + 文化发展（一）

- 所有者 / 分支：cloud/grok · `cloud/grok/TASK-007-lesson-01`
- 来源功能编号：F-15（新）、F-05、F-06、F-09、F-10

## 1. 需求（EARS）

- R1：当数据包里有 `lessons/<id>.json` 时，系统应把每节课显示为星图上 topic 里的一颗 📖 星，并连到它声明的相关节点。
- R2：打开一节课时，系统应先显示课前说明（准备什么、大约多长、建议阅读，有截止日期就显示），再按章播放短片；每条说法都带主张标签（事实 / 学界共识 / 主流解释 / 有争议 / AI推断 / 个人判断 / 框架），引用了来源的显示编号和链接。
- R3：章末有互动（猜测 / 分类）时，系统应在那里停下等学习者作答，揭晓答案、解释和来源，并记一条 play 事件。
- R4：自测全对（题数 ≥ 3）时，系统应写 quiz 事件并点亮这颗星（与 F-06 规则一致）。
- R5：学习者保存感想时，系统应写 `note{kind:"takeaway"}` 事件：dev 模式写进 `log/<device>.jsonl`，离线存本机并可导出、`log:import`。
- R6：只有学习者输入与 `close.phrase` 相同的文字（默认「完成」）且课已点亮时，系统才写 `done` 事件；之后课的状态在标题栏、目录、星图、顶部提示四处都显示「✅ 已完成」。
- R7：课的状态（未开始 / 进行中 k/N 章 / 已点亮·待完成 / 已完成）只由日志推算，浏览器版与引擎版一致。
- R8：课的格式校验应拒绝：「事实 / 学界共识」没有来源、引用不存在的来源、分类答案不在选项里、猜测答案越界、题目少于 3 道。
- R9：公开仓库不得跟踪 `lessons/`（示例包除外）。

## 2. 验收标准

- AC1：`npm test`（公开示例课）与 `LEARN_DATA_DIR=../learn-data npm test`（第一课）全过；第一课满足：章节合计 20–30 分钟、2–3 个互动、5–6 题、两部分（W0 / W1）、书架链接、截止 2026-10-23。
- AC2：Given dev + 临时数据包，When 在第一课里走完 8 章、3 个互动、6 题全对、保存感想、输入「完成」，Then `log/<device>.jsonl` 依次有 open、play（章节 / 互动）、quiz 6/6、note(takeaway)、done，且页面显示「✅ 已完成」。
- AC3：Given 离线 HTML，When 做完同样流程并导出 jsonl，Then `log:import` 导入后 `lessonStatus` 为 done。
- AC4：没点亮时「完成」输入框不可用；输入别的文字不写 done。
- AC5：模板里 `lessonStatus` 与 `engine/lib/lesson.ts` 在 5 组日志上结果完全一致。
- AC6：第一课所有「事实」条目都有来源；来源与核查记录列在 learn-data `lessons/u-lesson-01.md`。
