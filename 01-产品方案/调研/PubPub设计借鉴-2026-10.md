# PubPub 设计借鉴 → 学者方案（2026-10-24，CR-20261024-01）

## 结论
PubPub 是学术出版平台，不是学习产品。我们只借它「出版物骨架」的设计：版本、带类型关联、出处、锚定批注、元数据驱动重建。不借平台本身。

## 事实出处
- https://www.pubpub.org/ ：DOI、投稿评审、公开/私有讨论与批注、带类型的内容关联（review/commentary/supplement，可报送 Crossref）、PDF/Word/Markdown/LaTeX/JATS 导出。
- https://notes.knowledgefutures.org/pub/9h6l37lu ：Releases，主链接永远指向最新版，旧版提示去看新版；草稿历史可链接到任意时间点。
- https://legacy-help.pubpub.org/pub/pub-management-reference/release/2 ：讨论频道 Public / Private / Restricted。
- https://www.knowledgefutures.org/updates/2024-07-platform-tech-overview/ ：PubType、Workflow=Stage+Action、多层父子嵌套、格式无关。
- https://www.knowledgefutures.org/updates/2025-04-platform-update/ ：静态站点、元数据变更自动重生成 PDF/JATS、Legacy 2026-01 下线。

以下条目是基于以上事实的推断与设计。

## 1. 课的版本发布 · P1 · S · M1 · TASK-105
- 范围：课 JSON（`lessons/u-lesson-xx.json`）加 `version`（semver）、`released_at`、`release_notes`；schema 校验；课页头显示「v1.1 · 更新说明」；深链 `#/node/<id>@<version>` 打开指定版本，缺省最新；旧版顶部提示「有新版」；log 事件 `done`/`quiz` 带 `lesson_version`。旧版本存 `lessons/<id>/versions/<v>.json`（只增不改）。
- 完成标准：① u-lesson-01 标为 v1.0；② 改一处内容发 v1.1 后两个版本都能用深链打开，旧版有提示；③ 回复「完成」写入的 log 带版本号；④ 测试新增 schema 与深链用例全部通过。

## 2. 带类型的关联边加强 · P1 · S · M1 · TASK-106
- 范围：边类型新增 `continues`（下一课）、`supplements`（补充材料）、`reviews`（复盘/批评）、`cites`（课→节点出处）；星图图例与筛选；课与课之间显式连边（u-lesson-01 → U02）。
- 完成标准：① Atlas 校验认识新类型，0 警告；② 星图能按类型显示/隐藏；③ 第一课节点能看到「下一课」入口。

## 3. 结构化出处 + 引用本课 · P1 · S · M1 · TASK-107
- 范围：sources 统一为 CSL-JSON 子集（id/author/issued/title/page/URL）+ 自有字段 `reliability`（一手/学术/通俗/AI 推断）；章节结论用 `[@id]` 回链出处；课尾自动生成参考文献；「引用本课」按钮复制一行引用（含版本号与深链）。
- 完成标准：① 第一课 29 条出处全部迁移且通过校验；② 每章至少一处结论可点回出处；③ 无出处的断言被校验脚本列出（作为「待核实」清单）。

## 4. 锚定批注 · P2 · M · M2（第二步登录同步之后）· TASK-205（并入 TASK-203）
- 范围：在章节段落选中文字写批注，锚点 = 课 id + 版本 + 段落 id + 文本引用；写入 learn-data `annotations/<device>.jsonl`（只追加）；默认 Private；为以后预留 Restricted（他人可看不可写）。课升级版本后锚点按文本引用重新定位，失败的标「已失效」。
- 完成标准：① Mac 与手机各写一条批注，同步后两端都能看到并定位；② v1.0 写的批注在 v1.1 里仍能找到或明确标失效；③ 公开站点不泄露任何批注。

## 5. 课数据一改自动重建 · P2 · S · M2（随 #56 自动部署）· TASK-206
- 范围：GitHub Actions 中，课 JSON 或出处变动 → 重建课 HTML、课后速查卡（hyperknow 借鉴：一页要点 + 自测题）、可打印 PDF；产物附在 Pages 或 learn-data 的 `build/`。
- 完成标准：① 改第一课一个字，推送后 10 分钟内网页与 PDF 都更新；② 速查卡自动生成且与课版本号一致。

## 不借
DOI/Crossref/JATS 与学术评审（要会员费用、对个人学习无用）；多社区多角色与编辑后台（单人学习太重）；通用可配置 workflow 引擎（违背「更深不更大」）；迁到 PubPub 托管（Legacy 下线、Platform 收费、没有掌握度模型）；公开评论区（课程是否公开未定）。
