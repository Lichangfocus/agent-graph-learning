| F-01 | Atlas（全人类知识地图） | 领域 → topic → 节点 + 有类型的边；单文件 `atlas/world-map.json`（`learn.atlas.v1`），由 `atlas/src/` 构建；CC BY-SA 4.0 | id 全局唯一；边必须有 note + claim_type；prereq 不得成环；ready 节点必须 ≥3 道自测；改名/合并写 `atlas/migrations/` | M0 | ✅ v0.2：10 领域 · 33 topic · 47 节点（11 ready）· 59 边 · 0 警告；并入 scholar-engine v3；节点/边可带 `sources`（CR-20261018-02/04） |
| F-02 | 用户数据包（user pack） | 私有仓库 `learn-data`，`learn.userpack.v1`：profile / log / overlay / topics / annotations / units-private / curriculum / builds | 没有数据包时加载 `examples/demo-pack`；坏行只报告不中断；数据包不放代码 | M0 | ✅ |
| F-03 | 框架 / 数据分离 | `LEARN_DATA_DIR`（相对框架根，推荐 `../learn-data`）决定读哪个数据包；用个人数据构建的产物只写进 `<data>/builds/` | 公开仓库禁止跟踪 profile/log/units-private 等路径与符号链接（`npm run check:privacy`）；私人素材经 `data:link` 只在本机链接 | M0 | ✅ |
| F-04 | 覆盖层合并 | 用户节点 / 边 / topic 叠加到 Atlas，**只引用、不改写**；用户 id 以 `u-` 开头 | 与 Atlas 同 id、重复 id、悬空边、未知领域 → 丢弃并报错；用户 prereq 造成环 → 报错 | M0 | ✅ |
| F-05 | 学习日志 | `log/<device>.jsonl` 只追加；事件 `open/play/quiz/lit/review/note/ask/topic_create/link_create` | 设备名只允许 `[a-z0-9_-]`；时间戳必须带时区；多设备合并按时间排序 | M0 | ✅（读写 + `npm run log` + dev 应用直接写回 `/api/events/` + `npm run log:import`，CR-20261018-03） |
| F-06 | 掌握度 5 级 | 由日志推算，不单独存：seen / learning / lit（3 题全对或 lit 事件）/ mastered（lit 后 ≥1 天复习通过）；有未亮 prereq → locked | 只显示个数，不显示百分比；locked 是软锁，仍可打开；等级不回退 | M0 | ✅（引擎 + 星图同一规则，测试比对） |
